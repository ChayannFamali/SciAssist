## Задача
Верни строго JSON (без пояснений, без ```):
{
  "method": "Описание предложенного метода/архитектуры (4-6 предложений)",
  "key_ideas": ["идея 1", "идея 2", "…"],
  "experiments": "Какие эксперименты проведены, на каких датасетах, метрики",
  "results": "Ключевые численные результаты, сравнение с baseline"
}

key_ideas — объединение идей всех частей без дублей. В experiments/results включай ВСЕ числовые результаты из всех частей (точности, размеры выборок, проценты, приросты) — не выборку, а полный перечень.
Язык: русский. Термины — английский. Только JSON.
